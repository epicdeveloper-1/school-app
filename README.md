# Weekly Strategy

A Next.js school week planner. Set one weekly focus, add daily priorities, and track subject targets. Plans save in the browser (localStorage).

## Requirements

- Node.js 20+
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Dev server on port 43123 |
| `npm run build` | Production build         |
| `npm run start` | Start production server  |
| `npm run lint`  | Run ESLint               |

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
