# Weekly Strategy — UW 2A Fall 2026

**Goal:** Finish the checklist → you’re on track. Minimal–medium effort, stay caught up, protect free time and basketball.

**Default week** = no MATH 235 quiz. See [Week variants](#week-variants) when that changes.

## Hard caps

- Locked-in study/work ≤ ~4 hours/day (Monday quiz-prep nights may use the full 2–4h study block).
- Job: 4–6h/week on a normal week; scale down with busyness.
- After Water Boys (Thu ~9/9:30): wind down only — no focused study.

Related: [WEEKLY_STRATEGY_CONTEXT.md](./WEEKLY_STRATEGY_CONTEXT.md) (full term data for future you / agents).

## Default week checklist

### Monday — quiz prep night (highest priority academic night)

**Classes:** MATH 235 12:30 · AMATH 250 2:30 · MATH 237 4:30

- [ ] Meals (lunch before/around first class; dinner 5–7)
- [ ] Optional: basketball morning (~10–12) or short evening run if energy left
- [ ] CS 234: this week’s module chunk + any exercise due soon (keep moving; don’t binge)
- [ ] Mon night lock-in (2–4h): shared prep for Tue MATH 237 quiz + AMATH 250 quiz until comfortable (problem sets / textbook Qs / notes). MATH 237 slightly first if short on time.
- [ ] Catch up on any unchecked boxes from the weekend

### Tuesday — quiz morning, open afternoon

**Classes:** MATH 237 tut 8:30 · AMATH 250 tut 10:30  
(Quiz mornings: wake early enough for 8:30 — this breaks the usual 10–12 wake.)

- [ ] MATH 237 quiz / tutorial block
- [ ] AMATH 250 quiz / tutorial block (lighter priority than 237 if you had to triage Mon night)
- [ ] Meals
- [ ] Open afternoon: CS 234 modules / Learning Activity progress / light review or basketball or chill
- [ ] Optional light evening study only if Mon didn’t finish solidification (keep under the daily cap)

### Wednesday — classes + Vocal Tech (7–9)

**Classes:** MATH 235 12:30 · AMATH 250 2:30 · MATH 237 4:30 · Vocal Techniques 7–9pm

- [ ] Meals (dinner early enough to make Vocal Tech)
- [ ] Between classes / early evening before 7: CS 234 or light course review (gaps are real — use one of them)
- [ ] Vocal Techniques 7–9
- [ ] After 9: optional light wrap-up or chill (you can study Wed nights; don’t force a deep session)

### Thursday — voice → ball → study → MATH 235 slot → Water Boys

- [ ] Voice lesson (time from app Settings; default 11:00–11:45)
- [ ] Basketball if lesson timing allows (voice → ball → study order)
- [ ] Focused study block before 5:30 (CS 234 and/or MATH 235 weekly review — default week = no 235 quiz)
- [ ] Dinner window as needed around rehearsal
- [ ] MATH 235 tutorial 5:30–6:20 (quiz weeks: this is the quiz — see variants)
- [ ] Water Boys 6–9 or 6:30–9:30 (OK ~20 min late if 6–9)
- [ ] Wind down after rehearsal — no lock-in study

### Friday — light academic day + next-week setup

**Classes:** MATH 235 12:30 · MATH 237 4:30 · (no evening rehearsal this term)

- [ ] Meals
- [ ] Basketball morning or between classes if you want a weekday session
- [ ] CS 234 lecture content: this week’s modules (+ LA progress if needed) + notes/outline for final
- [ ] Update / tidy summary sheets (MATH 235, 237, AMATH, CS 234) — short pass, not a rewrite
- [ ] Glance at next week’s deadlines (CS calendar + quiz weeks)
- [ ] Job hours if this is a light/normal week
- [ ] Flex / social / chill

### Saturday — catch-up + job + fun

- [ ] Brunch window
- [ ] Academic block (pick what the week needs; don’t do all every Saturday):
  - Textbook / problem-set time (MATH 237 / AMATH / MATH 235 as needed)
  - CS 234 problem solving: exercise / quiz / asst progress
- [ ] Job block (good default day for hours)
- [ ] Basketball (weekend session — social/night games count)
- [ ] Protect real free time — Saturday is also for fun

### Sunday — light setup for Monday night

- [ ] Brunch / dinner windows
- [ ] Light split review if useful: skim Tue quiz topics (237 + AMATH) so Mon night is solidification not first exposure
- [ ] Optional basketball
- [ ] Early-ish wind-down so Mon night quiz prep is possible
- [ ] Flex if already ahead

## Flex windows (catch up or chill)

These are where slack usually appears — not obligations.

| Window | Why it’s flexible |
| --- | --- |
| Tue afternoon/evening | Classes done by ~11:20; quizzes already written |
| Fri after MATH 237 | No rehearsal; natural decompress + light admin |
| Sat after academic/job block | Prioritize staying on schedule first, then free |
| Sun if Mon quiz topics already skimmed | Especially free if CS is not due Mon/Tue |
| Thu between voice/ball and 5:30 | Only if study block finished early |
| Wed gaps between lectures | Short tasks only (CS popup/exercise slice) |

If the checklist is done, prefer chill over filling flex with extra work.

## Week variants

Use the default checklist, then apply the matching overlay.

### A — MATH 235 quiz week (tight gap: 1 week since last 235 quiz)

Dates with short gaps: e.g. Oct 1 (after Sep 24), Nov 5 (after Oct 29), Dec 3 (after Nov 26).

- Wed night: light MATH 235 pass (formulas / summary sheet / a few textbook Qs)
- Thu: morning-of solidification before 5:30 → quiz in the 5:30–6:20 slot → Water Boys → wind down
- Trim CS deep-work and job hours (busyness)

### B — MATH 235 quiz week (long gap: ~3+ weeks of content)

e.g. Sep 24, Oct 29, Nov 26.

- Weekend before: MATH 235 problem sets / textbook (real first pass)
- Tue or Wed night: second pass (can be lighter if weekend was strong)
- Thu: solidification + quiz 5:30–6:20 → Water Boys → wind down

### C — Heavy CS 234 week (quiz + exercise + asst stacked)

Rough pattern: weeks 2–4, 7, 10, 12 — confirm on CS calendar.

- Pull CS work earlier in the week (Fri/Sat ahead-of-time habit)
- Mon night still belongs to Tue math quizzes first; CS only after comfortable or in Tue/Wed gaps
- Learning Activities: schedule a dedicated block so they don’t collide with asst due dates
- Optional CS assts: skip unless midterm/final practice season

### D — Document-only stress weeks (don’t over-rebuild the strategy)

| When | Note |
| --- | --- |
| AMATH midterm week of Oct 19–23 | Documented in context file; shift weekend + Mon night toward AMATH past quizzes / problem sets as needed |
| Reading week Oct 12–18 | Catch up CS modules, summary sheets, optional asst practice, basketball, job — no default class rhythm |
| Late term / finals | Rebuild from context; keep CS 234 final prep + summary sheets central |

## Job hours by busyness

Encourage some work every week, but free time is not automatically “should work.”

| Busyness score | Signals (count how many apply) | Target job hours |
| --- | --- | --- |
| 0–1 Light | No 235 quiz; CS light; quizzes felt easy Mon night | ~6h |
| 2 Normal | Routine Tue quizzes + steady CS | 4–5h |
| 3 Busy | 235 quiz week or CS asst due or Learning Activity deadline | 2–4h |
| 4+ Protect | 235 quiz + CS stack, or midterm week, or falling behind checklist | 0–2h (minimal / skip) |

Default placement: 1–2 weekend blocks, leftover on Friday flex. Never schedule job over Mon night quiz prep or Thu pre-rehearsal study when behind.

## Basketball (3–4× / week, ~2h)

Aim for three or four sessions; mix mornings and social nights.

| Slot | Notes |
| --- | --- |
| Mon/Wed/Fri morning (~10–12) | Before 12:30 classes — good “get active” default |
| Tue/Thu evening | More people; Thu only if voice + study still fit before 5:30 |
| Weekend | 1–2 sessions; counts toward the 3–4 |

Skip a session before a brutal Mon night or a long-gap 235 study weekend if energy is the bottleneck — activity supports the term, it doesn’t replace Mon quiz prep.

## CS 234 weekly rhythm (async)

Stay continuous so the 87% final is not a scramble. Popups complete naturally while doing modules.

Each week, roughly:

- Modules for the current week checklist
- Exercise on the suggested timing
- Quiz work early (due 4:00 PM Waterloo, not midnight)
- Assignment progress when one is open (optional mark weight — still useful before exams)
- Learning Activity progress toward all 4
- Notes / outline / summary sheet update for final review

Due-date source of truth: course calendar in context file (all quizzes & assts 4:00 PM).

## Success rule

If the day’s boxes are done and you’re inside the time caps, **stop**. Flex is for catch-up or fun — not for inventing more work.
